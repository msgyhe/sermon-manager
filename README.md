# 말씀과 기도

설교문과 기도문을 작성하고 예배별로 연결해 관리하는 개인용 사역 작업실입니다.

## 현재 개발 단계

5단계 출시 준비 및 AI 작성 보조까지 구현되었습니다.

- 대시보드와 반응형 공통 내비게이션
- 설교문·기도문 목록 및 편집
- 문서 상태, 성경 본문, 태그, 예배 연결
- 기도 종류와 목표 낭독 시간
- 글자 수와 예상 낭독 시간 계산
- 예배 일정 등록 및 준비 상태 확인
- 제목·본문·태그 통합 검색
- 브라우저 로컬 저장소 자동 저장
- 이름을 붙이는 수동 버전 저장과 복원
- 예배별 실제 사용본 스냅샷 보존
- 글자 크기와 밝기 조절이 가능한 낭독 전용 화면
- 휴지통 이동, 복원과 영구 삭제
- 전체 데이터 JSON 백업과 복원
- 낭독 화면에서 인쇄 및 PDF 저장
- 기본 템플릿 적용과 사용자 템플릿 저장
- 저장된 버전과 현재 원고의 문단 비교
- 본문 연구, 예화, 공통 문장, 참고 자료를 관리하는 자료실
- Electron 기반 Windows 데스크톱 앱
- SQLite 로컬 데이터베이스 저장
- 앱 전용 폴더 파일 첨부와 열기
- 하루 한 번 자동 백업 및 최근 10개 보관
- 한글 설교문·기도문 DOCX 내보내기
- NSIS Windows 설치 프로그램 생성
- 첨부 파일 삭제와 다시 첨부
- TXT·DOCX 기존 원고 가져오기
- 긴 문장과 반복 단어, 예상 낭독 시간 점검
- OpenAI Responses API 기반 문장 다듬기·요약·기도문 초안
- Windows 보안 저장소를 이용한 API 키 암호화
- AI 외부 전송 미리보기, 민감 정보 일부 제외와 비교 적용
- 주제·키워드·본문·대상·목표 시간 기반 설교문·기도문 초안 생성
- 생성 전 필수 입력 검증과 외부 전송 내용 확인
- 생성 후 구조화된 AI 검증 점수, 위험 항목, 수정 권고와 확인 질문
- 검증 전 적용 경고와 사용자 승인 후 원고 반영

다음 개발 단계에서는 전용 앱 아이콘, 코드 서명, 자동 업데이트, 실제 사용자 검수와 배포 채널 구성을 진행합니다.

## 실행

```bash
npm install
npm run dev
```

데스크톱 개발 모드:

```bash
npm run dev:desktop
```

프로덕션 빌드 확인:

```bash
npm run build
```

Windows 설치 파일 생성:

```bash
npm run build:desktop
```

## 현재 저장 방식

브라우저 개발 모드에서는 로컬 저장소를 사용합니다. Windows 데스크톱 앱에서는 사용자 데이터 폴더의 SQLite 데이터베이스와 전용 첨부·백업 폴더를 사용합니다.
